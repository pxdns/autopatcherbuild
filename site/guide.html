How to use it

Four steps, on any computer with Java 17 or newer.

  1. DownloadOpen Versions and download the patcher for your version.
  2. Run itStart it with java -jar Eaglercraft-<version>-patcher-cli.jar. Check your Java with java -version.
  3. Choose your jarPoint it at your own official client jar for that version. You need a copy of the game you are allowed to use.
  4. BuildBuild a standalone page or a source project from the same run. Everything is made on your machine.
