Legal

What this project contains, how it is licensed, and where to send a copyright report. Last updated 28 October 2026. Not legal advice.

What this project does and does not contain

Contains
The run scripts, the Java patcher, the tools, this site and the docs.
Does not contain
Minecraft code, decompiled Minecraft source, Minecraft assets, or a built client.
A release holds
The patcher program and a patch bundle: new files written for this project, plus changes that consist only of added lines. Removed or replaced original lines are recorded as hashes, never as text.
Checked by
Every build runs a leak scan that fails if the bundle contains a run of lines copied from Minecraft's decompiled code.
You supply
Your own copy of the game. The run script downloads Mojang's official client jar and mappings straight from Mojang's servers onto your computer and checks their SHA-1 values. They are never uploaded or republished here.
What you build
A client you generate contains Minecraft's code and files. Keep it for your own use unless you have the right to distribute it.

This is how the project is designed to respect Mojang's terms. It is not legal advice and not a guarantee.
