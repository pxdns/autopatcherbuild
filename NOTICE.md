## What this project does and does not contain

- It contains **no Minecraft code, no decompiled Minecraft source and no Minecraft assets**, and nothing here is a built client.
- A release holds the patcher program and a **patch bundle**: new files written for this project, plus changes that
  consist only of added lines. Removed or replaced original lines are recorded as hashes, never as text.
- Every build runs a leak scan that fails if the bundle contains a run of lines copied from Minecraft's decompiled code.
- To use a patcher you need your own copy of the game. The run script downloads Mojang's official client jar and
  mappings directly from Mojang's servers onto your own computer and checks their SHA-1 values. They are never uploaded
  or republished here.
- A client you generate contains Minecraft's code and files. Keep it for your own use unless you have the right to
  distribute it.

This is how the project is designed to respect Mojang's terms. It is not legal advice and not a guarantee.
