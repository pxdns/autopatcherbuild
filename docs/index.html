Autopatcher

Pick a version, download its patcher, and run it with your own official Minecraft client jar. The jar is never included and never uploaded.

How to use it

  1. Download the patcher for your version below.
  2. Run it with Java 17 or newer: java -jar Eaglercraft-java -jar Eaglercraft-<version>-Setup.jarlt;versionjava -jar Eaglercraft-<version>-Setup.jargt;-patcher-gui.jar.
  3. Choose your own official client jar for that version when it asks. You need a copy of the game you are allowed to use.
  4. Build a standalone page or a source project from the same window.
